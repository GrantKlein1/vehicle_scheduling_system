Feature 6. Reservation
A driver submits a request for a reservation: 
Then the system checks if the requested vehicle has been assigned to anyone
The system checks if the driver is on the list of approved drivers for that vehicle type (ie a driver NOT on the list of approved drivers for golf carts would be denied a reservation request for a golf cart at this point)
Then the system either assigns the requested vehicle to the requestor(driver) or tells them the vehicle is not available.
Create a text file that has the details of the reservation
In the next feature this file will be used to send an email to the driver
Feature 7. Email
An email is sent to the driver when their reservation has been confirmed (right after they create it)
On the day before of the trip, the requestor should get an email (custom by area) with instructions for picking up the vehicle (what vehicle, designated parking for the vehicle, where to get the keys, what to do on return (fill with gas, clean up, where to put the keys), who to contact if there is an issue.
