Vehicle Scheduling
OC owns a fleet of vehicles number of cars, trucks, vans and golf carts that can be reserved and
reserved for use by OC faculty, staff, and sports teams.
Different OC areas (Athletics, Support Central, Maintenance) do the reservation of different
groups of vehicles.
An individual can make a vehicle reservation request (requested):
o Person or Team making the request
o Driver (on list of approved drivers)
o Start Data and Time (some only use dates)
o End Date and time (some only use dates)
o Destination (could be city or selected from known locations). – used for milage
estimate
o Number of people in trip.
o Note (from admin,requestor) Note type, Note text
An Admin/System assigns a Vehicle to the trip if available (reserved) or indicates that there is
not a current vehicle available (awaiting vehicle).
An email is sent to requestor when the reservation status changes.
On the day before of the trip, the requestor should get an email (custom by area) with
instructions for picking up the vehicle (what vehicle, designated parking for the vehicle, where
to get the keys, what to do on return (fill with gas, clean up, where to put the keys), who to
contact if there is an issue.
On the day of the trip the requestor picks up the key, takes the vehicle.
On the day of the return the requestor returns the vehicle to campus in the designated parking,
follows the return instructions and returns the keys to designated location.
On return requestor can submit a notice that the reservation/vehicle had issues, before, during
or after a trip.
o Low Gas
o Dirty
o Maintenance need
On return the area admin can make the request status returned

An Admin/Area Admin can log in and see a weekly schedule (calendar) of Vehicle
Request/Status/Vehicle.
An Admin/Area Admin can log in and see a list of request that need servicing. (need vehicle,
need to be checked in)
A Requestor can log in and see all their request and statuses.
A Maintenance person can log in person can view maintenance request, view list of vehicles,
log mileage and log Services done on a vehicle (repair, oil change, tire replacement)
A User should use Google Authentication (OC Credentials) to log in.
